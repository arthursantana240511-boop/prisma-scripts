PRISMA SCRIPTS — COMO USAR

1. Abra scripts.js e troque os links https://example.com pelos seus links finais.
2. Use o mesmo slug em scripts.js e gate.js.
3. Para publicar, envie index.html, get.html, style.css, scripts.js e gate.js para GitHub Pages ou Cloudflare Pages.

EXEMPLO DE LINK:
seusite.com/get.html?to=delta

IMPORTANTE: esta versão é estática. O link final ainda pode ser descoberto por alguém que inspecione o código. Para ocultá-lo de verdade, use um backend/redirector no servidor.
